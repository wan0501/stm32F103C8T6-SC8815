# STM32F103C8T6 + SC8815 双向 BUCK-BOOST 开关电源

本项目基于 **STM32F103C8T6** 微控制器和 **Silergy SC8815** 双向升降压控制器，设计了一款**可调双向 Buck-Boost 开关电源**，支持升压、降压以及双向功率传输。

## 项目概述

SC8815 是一款高效率、宽电压范围的同步升降压（Buck-Boost）控制器，支持 I²C 数字接口控制。本项目以 **STM32F103C8T6** 作为主控 MCU，通过 I²C 总线配置 SC8815 的工作模式，实现：

- **双向功率传输**：支持正向（降压输出）和反向（升压回充）两种工作模式
- **可调输出电压 / 电流**：通过按键 / 编码器 / 串口指令实时调节
- **信息显示**：OLED / LCD 屏幕实时显示电压、电流、功率等参数
- **闭环控制**：MCU 采集输出反馈，动态调整 SC8815 参数

### 应用场景

- 可调实验室电源
- 电池充电 / 放电管理
- USB PD 可调电源
- 便携式设备供电
- 太阳能 MPPT 前端

### SC8815 简介

SC8815 是 Silergy（现 Renesas）推出的同步升降压控制器，主要特性：

- **四开关 Buck-Boost 拓扑**： seamless 模式切换，无盲区
- **宽输入 / 输出电压范围**：2.7V ~ 36V
- **I²C 可编程**：调节输出电压、电流限制、开关频率等
- **高效率**：同步整流，峰值效率 > 95%
- **双向工作**：支持正向和反向电流
- **内置保护**：OCP、OVP、OTP、UVLO

### STM32F103C8T6 功能

- **I²C 主机**：配置 SC8815 寄存器，设定工作参数
- **ADC 采样**：采集输出电压、电流、温度等模拟量
- **显示驱动**：驱动 OLED / LCD 显示实时数据
- **用户输入**：按键 / 编码器调节电压和电流
- **通信接口**：UART 串口命令控制

## 硬件设计

### 功率级 — SC8815 外围

- **功率 MOSFET**：四颗 N-MOSFET 构成 H 桥 Buck-Boost
- **功率电感**：根据开关频率和电流选择合适感值
- **输入 / 输出电容**：低 ESR 陶瓷电容 + 电解电容
- **电流检测**：低阻值采样电阻 + 差分运放
- **自举电路**：上管驱动自举供电

### 控制级 — STM32 外围

- **I²C 上拉**：SC8815 的 SCL / SDA 上拉电阻
- **分压采样**：输出电压分压电阻网络连接 MCU ADC
- **电流采样**：芯片自带12位数ADC采样
- **显示接口**：I²C OLED（SSD1306）
- **用户输入**：按键

### PCB 布局要点

- **功率回路**：电流环路尽可能小，减少寄生电感和 EMI
- **大电流走线**：加宽敷铜或开窗加锡
- **散热**：MOSFET 底部过孔散热，功率器件布局分散
- **模拟 / 数字分区**：SC8815 模拟信号远离数字噪声
- **采样走线**：Kelvin 连接方式，避免共阻抗干扰

## 软件设计

### 主循环流程

```
系统初始化 → SC8815 I²C 初始化 → 参数配置
     │
     ├─ 循环：
     │   ├─ 读取 SC8815 状态寄存器
     │   ├─ ADC 采集输出电压 / 电流
     │   ├─ 处理用户输入（按键 / 编码器）
     │   ├─ 更新 SC8815 输出设定
     │   ├─ 刷新 OLED 显示
     │   └─ 处理串口命令（可选）
     │
     └─ 保护检测（过流 / 过温）
```

### I²C 寄存器配置

- **输出电压设定**：通过 I²C 写入 VOUT 寄存器
- **电流限制设定**：通过 I²C 写入 ILIM 寄存器
- **工作模式选择**：强制 DCM / CCM / 自动切换
- **状态读取**：读取故障状态、输入 / 输出电压等

### 通信协议（可选）

可通过 UART 串口发送指令控制电源：

| 命令 | 功能 |
|------|------|
| `SETV x.x` | 设置输出电压 |
| `SETI x.x` | 设置电流限制 |
| `GET` | 读取当前电压 / 电流 |
| `ON / OFF` | 输出使能 / 关闭 |

## 使用说明

### 硬件组装

1. 参照 `SC8815.SchDoc` 原理图焊接元器件
2. 确保功率 MOSFET 和电感选型正确
3. 检查极性：输入防反接保护
4. 初次上电建议串入限流电阻 / 电子负载

### 固件烧录

- 使用 **Keil MDK** 或 **STM32CubeIDE** 编译
- 通过 **ST-Link** 或 **UART ISP** 烧录至 STM32F103C8T6

### 操作方式

- **按键调压**：UP / DOWN 按键调整输出电压

### 注意事项

- 输入电压不要超过 SC8815 和 MOSFET 的耐压上限
- 大电流输出时注意散热，必要时加装散热片或风扇
- 严禁输出短路（依赖保护电路，但仍需避免）
